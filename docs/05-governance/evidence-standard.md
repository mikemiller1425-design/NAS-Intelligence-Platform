# Evidence Standard

## Evidence principles
- Evidence must be reproducible, attributable, and linked to a specific version of the artifact or plan.
- Generated artifacts should be hashed or otherwise integrity-protected where practical.
- Evidence must state what was observed, when, by whom or by what system, and under which version of rules.
- Evidence should never expose secrets or unnecessary private content.

## Evidence types
- Inventory manifest.
- Dry-run plan.
- Pilot dataset manifest.
- Approval record.
- Execution journal.
- Checkpoint log.
- Verification report.
- Reconciliation report.
- Rollback record.
- Sentinel alert history.

## Evidence requirements
- Stable ID.
- Date or timestamp.
- Source of truth.
- Integrity marker.
- Related phase or batch.
- Clear conclusion.
