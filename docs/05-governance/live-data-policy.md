# Live Data Policy

## Core rules
- Live NAS mutation is prohibited during blueprinting.
- Copy before delete is the default pattern for every phase.
- Source retirement requires hash verification and explicit approval.
- Protected vaults are not overwritten by default.
- Permanent deletion is unavailable in V1.

## Retirement and cleanup
- Retirement is a distinct, approved action, not an implied side effect of classification.
- Cleanup after a quarantine or pilot requires a separate decision and evidence bundle.
- Never equate near-duplicate similarity with deletion permission.

## Exception handling
- If a phase cannot meet the live-data policy, the phase does not start.
- If a source item is still needed as an authoritative record, preserve it.
