# Definition of Done

A blueprint item is done only when it is clear, traceable, and safe to hand off for independent review.

## Done criteria
- The artifact is written and linked from the correct section of the repository.
- The artifact does not authorize live NAS mutation unless the phase explicitly requires it and has approval gates.
- Provisional rules are labeled provisional until the operator confirms them.
- Open decisions are captured rather than hidden.
- Relevant acceptance requirements can test the artifact.
- Required evidence is named and realistically collectable.

## Not done
- An unresolved decision is left implicit.
- A destructive action is described without approval or verification.
- A helper doc contradicts the source manual.
