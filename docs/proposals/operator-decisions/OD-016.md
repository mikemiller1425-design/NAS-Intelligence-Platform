## The decision being requested

Which adapter accesses the NAS?

## Why it matters

Local mount, SMB, NFS, SSH/SFTP, or the vendor API. **This choice determines whether source retirement is reachable at all** — SFTP and vendor APIs cap identity confidence at advisory, which permanently waiver-gates G7. Review the `retirement_capable` derivation before deciding.

## What the operator must supply

The chosen adapter, justified per environment, decided with the retirement consequence visible.

## Default behaviour if unresolved

Fixture implementation proceeds against the capability contract. The live adapter rung stops.

## Evidence required to close

A written answer recorded against OD-016 in `docs/05-governance/open-decisions.md`, with the
supplying evidence attached.

## Register note (verbatim, for context)

> Local mount vs SMB vs NFS vs SSH/SFTP vs Synology API — justify per environment. Implementation may proceed against fixtures without this: `docs/03-architecture/adapter-architecture.md` and `docs/02-specification/preservation-model.md` define adapter behavior as a capability contract, not a product choice.
