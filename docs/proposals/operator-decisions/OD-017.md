## The decision being requested

What are the default report formats — Markdown, CSV, JSON, or a combination?

## Why it matters

Report packaging is a deliverable shape for the inventory, conflict, unresolved, duplicate, and reconciliation reports. It blocks report emission, not engine logic.

## Safe options

**1. JSONL for machine artifacts, Markdown for operator-facing**

Machine-readable evidence plus human-readable summaries.

*Tradeoff:* Two formats to maintain; matches the existing JSONL manifest direction.

**2. JSON only**

One format.

*Tradeoff:* Operator-facing reports become harder to read without tooling.

**3. Markdown only**

Human-readable throughout.

*Tradeoff:* Evidence becomes hard to verify mechanically, which the evidence standard discourages.

## Recommendation

**Option 1.** It matches the existing manifest direction and keeps evidence mechanically checkable while remaining readable without chat history, which a pilot acceptance row requires.

## What the operator must supply

The chosen format per report class.

## Default behaviour if unresolved

Engine rungs proceed. Report-emitting rungs stop.

## Evidence required to close

A format decision recorded against each report class.

## Cost of changing the decision later

Low. Report format can change without invalidating stored data.
