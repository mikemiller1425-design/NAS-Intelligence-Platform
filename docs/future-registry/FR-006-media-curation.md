# FR-006 — Media curation

## Purpose
Curate albums, highlights, and presentation sets from organized media.

## Dependencies
Stable taxonomy; optional FR-005 quality scores; review console maturity.

## Risks
Scope creep into a media product before migration safety is proven.

## Reason excluded from V1
V1 outcome is an organized, accountable NAS—not a curation studio.

## Promotion condition
Migration complete; maintenance mode stable; curation never mutates originals without plans.
