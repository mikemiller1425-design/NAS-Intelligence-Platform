# FR-010 — Project knowledge extraction

## Purpose
Extract structured knowledge from project folders and exports (including ChatGPT exports).

## Dependencies
Document analyzers; taxonomy for projects; privacy controls.

## Risks
Leaking proprietary project content into logs or external tools.

## Reason excluded from V1
V1 inventories and organizes; knowledge graphs are future enrichment.

## Promotion condition
Project destinations stable; extraction remains local; outputs never authorize file moves alone.
